GitHub 注册与 Token 指引

第 1 步 · 注册 GitHub（免费，约 3 分钟）
  • 电脑浏览器打开 github.com，点右上角 Sign up
  • 填邮箱 → 设置密码（这是 GitHub 网站密码，与仪表盘密码无关）→ 用户名（英文）→ 验证邮箱
    • 第 2 步 · 生成 Token（约 2 分钟）
  • 登录后打开 github.com/settings/tokens，点 Generate new token → Fine-grained token
  • 名字随意填（如 asset-vault），过期时间选 No expiration（永不过期）
  • 权限只勾选 Account permissions → Gists → Read and write，其他都不动
  • 点底部 Generate token，立刻复制显示的 token（只显示一次！），粘贴到本页「云端同步」表单里
    • 第 3 步 · 在每台设备上各连一次
  • 家庭电脑、公司电脑、手机浏览器分别打开本页 → 设置 → 云端同步，输入用户名和 Token → 连接并同步
  • 之后所有设备的数据自动保持一致（加密后存入你的 GitHub 私密 Gist，别人无法读取内容）
    • ⚠️ Token 相当于云盘钥匙，只填在本页，不要发给任何人。若怀疑泄露，去 GitHub 同一页面点 Revoke 作废即可。
